# Jewellery Product Builder Pro 3.0

Professional offline-first jewellery operations app.

## Version 3.0 additions

- Product Passport: metal, purity, weights, stone, certificate and engraving data per product.
- Rate Desk: local 24K, 22K, 18K and silver rate board with transparent jewellery estimate calculator.
- Service Desk: repair and custom-order job cards with estimate, advance, promised date and printable ticket.
- Workflow Board: received, at-bench, ready-for-pickup and delivered stages.
- Clienteling Queue: ready pickups and overdue work surface automatically.

Open `index.html` in a modern browser. The app continues to run offline and stores Version 3 data locally in the browser.
